# Modules

One page per plugin: what it does and the boundary it keeps.

## Documents

* [kb](/modules/kb.md) - Reads OKF knowledge bundles — what exists, what is in them and their text — from roots that must be configured rather than discovered, because a grant matches the pattern a rune passes and not the paths it resolves.
* [outline](/modules/outline.md) - Global structural code outliner that collapses function/method bodies for brace languages and Python, with piped `stdin` support.
* [qdev](/modules/qdev.md) - Quarkus Dev UI access over HTTP and a JSON-RPC websocket, observation-only until a project opts into named commands, with five controls governing what resolved configuration may reveal.
* [secret](/modules/secret.md) - Global masked config reader for `.env`, `.ini`, `.properties`, `.conf`, and `.json` files that scrubs secret values and inline URL credentials.
* [token](/modules/token.md) - Global token counter (OpenAI & Claude) for files, directories, and piped `stdin`, with budget warnings via `--warn`.
